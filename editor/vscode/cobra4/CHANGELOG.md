# Changelog

## 0.1.0 — initial release

- Syntax highlighting for `.c4` files (TextMate grammar).
- LSP integration via `c4 lsp` (diagnostics, hover, go-to-def,
  references, document symbols, completion, formatting).
- Snippets for the most common cobra4 constructs.
- Commands: run, build, fmt, check, test, serve, restart-lsp.
- Format-on-save (opt-in).
- Keybindings: Ctrl/Cmd+F5 (run), Ctrl/Cmd+Shift+T (test).

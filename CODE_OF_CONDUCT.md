# Code of Conduct

cobra4 is built by people in their spare time. We want everyone who
shows up — to file an issue, send a PR, ask a question — to leave
better off than they came.

## Expected behavior

- **Assume good faith.** Most misunderstandings are misunderstandings,
  not malice.
- **Be specific.** "This doesn't work" is harder to help with than
  "running `c4 run x.c4` on a file containing `each x in xs in parallel { ... }`
  raises `XYZ` on macOS Python 3.12".
- **Critique code, not people.** "This change adds a dispatch
  ambiguity" is welcome; "this is awful" is not.
- **English in public channels** so the conversation stays accessible.
  Italian, Spanish, anything else is great in private threads — just
  not at the expense of the broader community.

## Unacceptable behavior

- Personal attacks, slurs, harassment of any kind.
- Unsolicited sexual or violent content.
- Sustained disruption of discussions or contributions (the technical
  back-and-forth of code review is **not** disruption — bad-faith
  bikeshedding is).
- Publishing private information without consent.
- Weaponized "free speech" arguments to justify any of the above.

## Enforcement

Maintainers may, at their discretion:

- Ask a contributor to revise a comment / PR description.
- Edit or remove off-topic / hostile comments.
- Block participation in the repository (via GitHub interaction limits
  or outright blocks).

We aim to act in proportion to the behavior. A first slip gets a
private note; repeated patterns get acted on without further warning.

## Reporting

Please email the maintainers via the contact listed in the
[`cobra4-lang` GitHub organization](https://github.com/cobra4-lang)
profile. Reports are kept confidential.

---

This document is a deliberately short statement of principles, not a
ruleset. When in doubt: be the colleague you'd want to work with.
